## 学习建议

1. 先运行项目体验功能，再阅读文档
2. 第〇章是代码阅读指南，可以先浏览整体脉络，也可以学完后用作检查清单
3. 按顺序阅读，每章结合对应代码
4. 第三章到第八章是 Agent 核心能力的详解，建议重点阅读
